## 1. Вопрос (estimand)

Сохраняется ли локализация при беспорядке W = 20 на семействах `ring` и `wilson_ring` при росте s1, если IPR берётся по мультиплетам собственного пространства, а не по отдельным собственным векторам (которые зависят от базиса при вырождении)?

Описательная величина, не причинная. Вывод о физике S³×S¹ этим гейтом не делается.

## 2. Определение величины

Для собственных значений P (оператор S¹, размер s1) мультиплет — группа собственных векторов с зазором ≤ 1e-8. Пусть ρ_g(x) = Σ_{i∈g} |v_i(x)|² — диагональ проектора на мультиплет g, d_g = |g|.

- **Проекторный IPR** мультиплета: IPR_g = Σ_x ρ_g(x)² / d_g. При d_g = 1 совпадает с обычным IPR.
- Полный оператор блочно-диагонален по S³-индексу k (110 блоков при j_max = 3), блок k = d_k·I + P. Полный мультиплет λ = (k, g) с d_k + e_g = λ. Для полного мультиплета λ: IPR_λ = Σ_{(k,g)∈λ} Σ_x ρ_g(x)² / Σ_{(k,g)∈λ} d_g.
- **Выборка:** нижние мультиплеты по λ, включаются целиком, пока суммарная кратность ≤ n_low = ⌊0.10·N⌋, N = 110·s1. Фактическая доля выборки записывается в результаты (отклонение от 10 % возможно из-за целых мультиплетов).
- **Среднее по выборке:** Σ_λ IPR_λ·d_λ / Σ_λ d_λ.

**Соглашение (явное):** знаменатель d_λ, без множителя 2/(d+1). Базис-инвариантность проверяется численно в каждом прогоне: 10 случайных унитарных поворотов внутри мультиплетов, std должен быть ≤ 1e-12.

**Контрольная величина (только для сопоставления, не для вердикта):** наивный IPR по собственным векторам текущего блочного решателя (`solve_block_ipr_rstat` логика). Записывается рядом.

## 4. Пороги (фиксированы до запуска)

Вердикт считается по **обоим** семействам отдельно.

- **P1 (локализация):** среднее по сидам IPR_проект(W = 20) при s1 = 256 ≥ 0.25.
- **P2 (плато):** |наклон log IPR_проект(W=20) по log s1| на {64, 128, 256} ≤ 0.10.
- **P3 (контраст):** среднее по сидам отношения IPR_проект(W=20)/IPR_проект(W=0) ≥ 2.0 при каждом s1 ∈ {32, 64, 128, 256}.
- **P4 (контроли):** IPR_проект(W=20) у каждого контроля на s1 = 64 < 0.16 × (IPR_проект(W=20) ring на s1 = 64). Порог 0.16 взят из `docs/CLAIMS_AND_CAVEATS.md` (существующий порог контрольных наборов).

**Вердикт:**
- `PASS` — P1–P4 выполнены для обоих семейств.
- `FAIL` — хотя бы один из порогов не выполнен для любого семейства.
- Если наивный IPR даёт другой вердикт, это записывается как `DEFINITION_SENSITIVE` и не скрывается. Итоговый вердикт при этом остаётся по проекторному определению, поскольку оно выбрано заранее.

## 5. Что этот гейт НЕ доказывает

- Не подтверждает физику S³×S¹ и не отличает геометрию от дискретизации (это уровни 3–5 специфичности Gate 4B).
- Не заменяет Gate 4B и не пересматривает его вердикт.
- Не даёт вывода о пределе N → ∞ за пределами s1 = 256.
- Сиды ограничены 5 значениями; устойчивость к выбору сидов — только внутри этого набора.
