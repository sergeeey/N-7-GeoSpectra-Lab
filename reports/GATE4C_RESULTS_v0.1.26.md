# Gate 4C — результаты (v0.1.26)

**Предрегистрация:** `reports/GATE4C_PROJECTOR_IPR_PREREG_v0.1.26.md` (зафиксирована до запуска).
**Скрипт:** `scripts/gate4c_projector_ipr.py`. **Сырые данные:** `results/gate4c_projector/results.json`.
**Запуск:** 2026-11-05, exit code 0.

## Итоговый вердикт по предрегистрации

**FAIL** для обоих семейств (`ring`, `wilson_ring`). Причина одна: порог P4 (контроли).

| Порог | ring | wilson_ring |
|---|---|---|
| P1 (IPR_proj(W=20) при s1=256 ≥ 0.25) | PASS (0.3483) | PASS (0.2527) |
| P2 (\|наклон log IPR\| на 64–256 ≤ 0.10) | PASS (0.026) | PASS (-0.042) |
| P3 (контраст ≥ 2.0 при s1 = 32…256) | PASS (5.5× … 45.5×) | PASS (8.0× … 64.7×) |
| P4 (контроли < 0.16 × ring при s1=64) | **FAIL** | **FAIL** |

## Что не прошло и почему

P4 не выполнен, потому что контроль `broken_wilson` (scrambled) локализован **сильнее**, чем ring-референс:

| Контроль | s1=16 | s1=32 | s1=64 |
|---|---|---|---|
| random Hermitian, IPR_proj | 0.00114 | 0.00057 | 0.00028 |
| broken Wilson (scrambled), IPR_proj | 0.546 | 0.475 | 0.546 |
| ring reference, IPR_proj(W=20), s1=64 | — | — | 0.311 (среднее по сидам) |

Порог P4 при s1=64: 0,16 × 0,311 ≈ 0,050. Random Hermitian его проходит. Scrambled Wilson — в 1,75 раза выше референса, а не ниже.

Это **результат, а не ошибка кода**. Предрегистрация ожидала, что контроли не воспроизводят локализационный паттерн. Scrambled Wilson его воспроизводит и даже усиливает. Порог 0,16 взят из `docs/CLAIMS_AND_CAVEATS.md`; я не проверял, к какому именно контролю он относился (возможно, к `wilson_mode="disabled"`). Это нужно проверить до любых выводов из этого порога.

## Замечание о флаге DEFINITION_SENSITIVE

В JSON для семейств стоит `definition_sensitive: true`. Это **артефакт кода**: P4 вычислялся только для проекторного определения (`ipr_naive` P4 не считался), поэтому вердикты «проекторный FAIL / наивный PASS» не сравнимы по P4. По P1–P3 оба определения дают одинаковые выводы: разница IPR ≤ 1 % при s1 = 256 для wilson_ring и ≤ 2 % для ring (см. таблицу в `GATE4C_PROJECTOR_IPR_PREREG`). Флаг в JSON не использовать как физический вывод.

## Проверки корректности

- **Инвариантность:** max std по 10 поворотам внутри мультиплетов = 5,6e-17 (36 случаев, s1 ≤ 64).
- **Согласованность:** полный dense-проектор на s1 = 16 совпадает с редуцированной формулой с точностью 4e-16 для ring и wilson_ring.
- **Доля выборки:** 0,991–1,000 для ring и 0,920–1,000 для wilson_ring (целые мультиплеты, отклонение от 10 % ожидаемо).

## Что это значит для физики

- P1–P3 (плато и контраст) **воспроизводятся scrambled-Wilson контролем**. Значит, сами по себе IPR-плато и контраст не отделяют геометрию от беспорядка на этом наборе. Это согласуется с выводом Gate 4B (GEOMETRY_AGNOSTIC) и не добавляет новой физики.
- Гейт не выдаёт положительного результата о S³×S¹ физике.

## Ограничения

- 5 сидов, только W = 20 и W = 0, только alpha = 0.
- Контроли только на s1 ≤ 64 (dense eigh на N = 7040 — верхний предел по времени).
- P4 сравнивает контроль с ring-референсом; для wilson_ring это строгий, но заранее объявленный выбор.
