# Gate 4C — устойчивость вердикта к выбору определения IPR (v0.1.26)

**Источник чисел:** средние по 5 сидам из `results/gate4c_projector/results.json`, поле `verdict.*.ipr_*.P3_ratios` и `P1_value` (скрипт `scripts/gate4c_projector_ipr.py`). Расчёт сделан 2026-11-05.

## Что проверяли

Меняется ли вердикт по порогам P1–P3, если заменить проекторный IPR на наивный (среднее по собственным векторам)?

## Результат

| Величина | ring: проекторный / наивный | wilson_ring: проекторный / наивный |
|---|---|---|
| Контраст W=20/W=0, s1=32 | 5,5 / 7,4 | 8,0 / 8,1 |
| Контраст, s1=64 | 11,5 / 15,0 | 17,1 / 17,2 |
| Контраст, s1=128 | 23,6 / 31,2 | 32,7 / 32,7 |
| Контраст, s1=256 | 45,5 / 62,0 | 64,7 / 64,7 |
| IPR(W=20), s1=256 | 0,348 / 0,348 | 0,253 / 0,253 |

## Вывод

- **P1–P3 одинаковы для обоих определений** (все PASS). Вердикт устойчив.
- **Абсолютные числа зависят от определения**: контраст ring при s1=256 отличается примерно в 1,4 раза; у wilson_ring разница меньше 0,1 %.
- Значит, утверждать «контраст ≈ X» без указания определения нельзя. Утверждать «контраст ≥ 2» можно при обоих.

## Ограничения

- Один сид в этой таблице; устойчивость по 5 сидам — в `results.json`.
- Таблица не заменяет предрегистрацию: она описывает чувствительность, а не новый вердикт.
