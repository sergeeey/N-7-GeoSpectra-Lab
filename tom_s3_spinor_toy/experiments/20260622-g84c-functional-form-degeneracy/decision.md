# G84C Decision — Functional-Form Degeneracy Negative Control

**Date:** 2026-06-22  
**Verdict:** `FUNCTIONAL_FORM_DISTINGUISHABLE`

## Result

The inverse-square normalized shape is distinguishable from the tested
positive-power alternatives on the project-relevant interval.

The key analytic fact is the sign clash at `rho0 = 1.090`:

- value matching between `exp(-a * rho^6)` and `exp(-b / rho^2)` gives
  `b = a * rho0^8`;
- slope matching gives `b = -3 * a * rho0^8`.

For positive `a, b` these cannot both hold.

## Numerical control

The fit search was run on:

- narrow: `[1.05, 1.15]`
- project-relevant: `[0.9, 1.3]`
- wide: `[0.8, 1.5]`

The alternative forms were fit against the normalized inverse-square target
with a single shape parameter. The project-relevant fit remains outside the
audit threshold.

## Interpretation

This is not a physical derivation. It is a negative control showing that the
inverse-square profile is not merely a trivial local reparametrization of
`exp(-a * rho^6)` or `exp(-a * rho^12)` near the working point.

The comparison is sensitive to the declared sensitivity threshold, which is
explicitly audit-defined because the repository does not provide a project-wide
functional-form tolerance.

## Consequences

- `VALUE_ONLY_DEGENERACY_SLOPE_FAILS` is not the best description here because
  the interval-level fits are distinguishable, not just the local slope.
- The inverse-square ansatz remains a live functional hypothesis, but it is now
  separated from the positive-power alternatives.
