# GeoSpectra Compactification Audit — External Summary

## What this is

GeoSpectra is a falsification-first toy compactification audit. It is not a
completed string compactification, and it is not a completed no-free-parameter
derivation.

The useful output so far is a disciplined map of what the current framework can
support, what it cannot support, and what an external UV/string completion would
have to provide.

## What was checked

The repository explicitly checked and exhausted the main internal routes studied
within the current framework that could have produced a strong first-principles
completion:

- spectral/geometric routes to an inverse-square non-perturbative exponent;
- the standard gauge-reduction / gaugino-condensation bridge;
- spectral / proper-time / Poisson / theta / saddle routes;
- dual-modulus and warp-factor routes;
- physical mass-ratio extraction from the reduced action;
- the right-handed neutrino Majorana channel.

## Current conclusions

- `lambda` remains a free phenomenological coupling inside the current
  framework.
- `m_mod/m_KK ≈ 2.02%` is only a coordinate-curvature proxy.
- the more conservative metric-only canonical proxy is approximately `0.252%`.
- no confirmed physical mass ratio exists without a full reduced 4D Einstein-
  frame action.
- exact `B-L` forbids a bare right-handed Majorana mass in the current branch.
- the current neutrino sector is Dirac-only unless a `B-L = 2` breaking sector
  is added.

## What a UV/string completion would need to provide

1. A microscopic origin of `exp(-lambda/rho6^2)`.
2. A derived effective gauge-kinetic modulus or instanton action with inverse-
   square `rho6` dependence, or a different justified mechanism.
3. A derived value of `lambda`, not a post-hoc fit.
4. A microscopic uplift/counterterm sector if a Minkowski minimum is claimed.
5. A full reduced 4D Einstein-frame action with a canonical radion and a
   same-frame KK scale.
6. A `B-L = 2` scalar/operator/sector if Majorana or seesaw neutrinos are
   desired.

## What may be useful to others

- A reproducible no-go map.
- A compact list of UV completion requirements.
- A clear target for model builders.
- A warning against confusing coordinate-curvature proxies with physical
  masses.

## What is not claimed

- No completed string compactification is claimed.
- No Standard Model derivation is claimed.
- No first-principles `lambda` derivation is claimed.
- No confirmed physical mass-ratio prediction is claimed.
- No Majorana or seesaw neutrino mechanism is present in the current branch.

## Bottom line

The current GeoSpectra framework is useful as a falsification-first audit of a
candidate compactification toy model. It is not yet a finished UV-complete
theory, but it now has a precise boundary map for what external completion must
supply.
