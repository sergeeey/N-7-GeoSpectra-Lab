# Claim — Round97 (A7 from goal-expansion-100): SU(4)-Charged Content
Exhaustiveness Check

**Question type:** Descriptive (grep-verifiable robustness check on an
already-established finding, not a new hypothesis).

## Section 1 — Background

Round90 found the cubic `SU(4)_{PS}³` anomaly (`A(4,2,1)=+2`,
`A(4̄,1,2)=-2`, sum=0 only with both present) as the one channel that
DOES show a forcing pattern — IF `SU(4)_{PS}` were geometrically gauged
(blocked by gate G97). Round95 relied on this being the EXHAUSTIVE list of
`SU(4)`-charged fields in `preprint.tex` (E17's own claim). This round
directly attempts to falsify that exhaustiveness claim: is there any OTHER
`SU(4)`-charged field in `preprint.tex`, besides `(4,2,1)`/`(4̄,1,2)`, whose
presence would change the cubic-anomaly sum — in particular, could a
vector-like (non-chiral) spectator make the sum cancel WITHOUT requiring
both `t`-sectors?

## Section 2 — Pre-registered criteria

- **NO-GO CONFIRMED (round90/95's exhaustiveness holds):** grep of
  `preprint.tex` finds no additional chiral `SU(4)`-charged fermion field
  beyond `(4,2,1)`/`(4̄,1,2)`.
- **COUNTEREXAMPLE FOUND:** an additional chiral `SU(4)`-charged fermion
  field exists, whose anomaly contribution would change the analysis.

## Section 3 — What this does NOT test

Does not reopen gate G97 (whether `SU(4)` is geometrically realizable at
all) — that is a separate, still-open question (round96-goal-expansion-100
A1/E2). This round only checks whether, IF `SU(4)` were gauged, the
`(4,2,1)`/`(4̄,1,2)` cubic-anomaly analysis is based on a complete field
list.
