## Часть 1 — Bridge F': triality на clutching map (novelty-check → условный раунд)

### L0 gate (EstimandOps)

**Question type:** Descriptive.
**Entity:** transition/clutching function `θ: S⁵ → SU(3)` канонического
`G₂→S⁶` principal bundle, и его три triality-образа `θ_v, θ_s, θ_c`.
**Falsifiable predicate:** является ли `[θ_v]+[θ_s]+[θ_c] = 3·[θ]` в
`π₅(SU(3)) ≅ ℤ`, где `[θ]=1` — уже установленный класс канонического
вложения (см. G33-A1, `c₃(T^{1,0}S⁶)=χ(S⁶)=2`).
**Measurable outcome:** явное вычисление или строгий алгебраический аргумент
для классов `[θ_v], [θ_s], [θ_c]` через уже сертифицированный аппарат этого
проекта (`so8_basis()` из G102, `su(3)⊂g2` embedding, `solve_triality_partners`
из C62) — НЕ через внешние источники и НЕ с нуля.
