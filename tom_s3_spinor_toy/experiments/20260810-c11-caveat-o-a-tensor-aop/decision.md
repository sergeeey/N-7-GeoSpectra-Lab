## The question C52 left open

C52 proved orientability fails because `π_D(c)` is local and `γ = U_ι⊗s1` is not — using
the `A`-valued cycle. The `Z_n(A, A⊗A°)` formulation puts `J b* J⁻¹` factors into `π_D`,
and those are local only if `JAJ⁻¹` is — which C50/C51 gave **only** for `A ⊇` the full
twisted diagonal, i.e. not in C52's own regime.

**So the escape was: `J` supplies the `U_ι` the algebra cannot.**

## The escape was real (O1)

Shrinking `B` genuinely enlarges `A'`. With `B =` the `ι`-**even** functions, the
commutant of `B` on `H_M` has **dimension 24** in the model, and [VERIFIED-numpy] every
element decomposes as `m + m'·U_ι` with `m, m'` bundle endomorphisms — `U_ι` itself is in
there. `m·U_ι` commutes with `b` exactly when `b∘ι = b`, which is why the `ι`-even choice
is the one that opens the door.

## But `J` cannot walk through it (O2)

```
[D_M, m + m'U_ι] = [D_M, m] + {D_M, m'}·U_ι
```
[VERIFIED-numpy] the identity holds exactly, and `‖[D_M, m'U_ι]‖ = 11 → 19 → 35 → 67` as
the cutoff rises — **order one**, unbounded. `[D, J b* J⁻¹]` is **bounded**, because
`[D, b*]` is and `J` is antiunitary. Therefore `JAJ⁻¹` is **`U_ι`-free**, hence local, and
CAVEAT O closes in this regime.

*(The order-counting — `{D_M,m'} = [D_M,m'] + 2m'D_M` is order one while a bundle
endomorphism's `[D_M,m] = c(dm)` is order zero — is `[INFERRED-analytic]`, exactly as in
C50. The toy has no unbounded operators.)*

## The extreme case needs different bookkeeping (O3)

With `B = C·1`, `A' ` is **everything** — including non-local pseudodifferential operators
like `sign(D_M)⊗s1` that have bounded `[D,·]`. So locality is not the argument there.
Instead track the `H_M` factor: `[D, 1⊗I] = 0` and `[D,u] = −3i(I⊗s2)`, so
[VERIFIED-numpy] the algebra generated by `A ∪ [D,A]` (8 elements) has `H_M` factor
**identically the identity**. `γ`'s `U_ι` could then only come from `J b* J⁻¹` — which O2
has just excluded.

## Both checks were built to be able to fail

- **O4 (discriminator):** *allow* `J u J⁻¹ = U_ι⊗s1` and `γ` is reproduced **exactly**
  (`a⁰ = 1⊗I`). So the obstruction is precisely the boundedness of `[D, JuJ⁻¹]`, not a
  shortage of algebra and not genericity.
- **O3 counter-case:** admitting `U_ι⊗I` as an extra generator breaks the `H_M`-identity
  property in **8 of 16** elements.

## Two of my own errors, caught and recorded

1. **O1's split was wrong.** The first version used the Z₂ average
   `½(T + U_ι T U_ι)` — which reconstructs `T` correctly but is **not** a bundle
   endomorphism, because `U_ι T U_ι` maps the `(c,c')` block to `(c',c)` and the average
   keeps `X`-off-diagonal entries. The check returned **False for a true claim**. Correct
   split is by **`X`-block**: block-diagonal part is the bundle endo, the remainder is
   supported exactly on `ι`-pairs and returns to block-diagonal form on right-multiplying
   by `U_ι`.
2. **O3 was hardcoded.** `h_m_always_identity = True` was asserted with a comment — the
   **fifth** instance this session of a check that cannot fail. Replaced by explicit
   algebra generation plus the counter-case above.

## Kill Analysis

**Killed:** C53, and with it CAVEAT O — the last sub-point C52 left open. The `A⊗A°`
formulation does **not** repair orientability.

**Not killed — CAVEAT O′, named rather than hidden:** `J u J⁻¹` could be a **sum** in
which a `U_ι` term's unbounded commutator **cancels** against another unbounded term. A
finite model has no unbounded operators and cannot exclude it. Such a `J` would have to
satisfy order-zero, `J² = ±1` and `JD = ±DJ` **simultaneously with that fine-tuning** —
and C50's boundedness argument pushes against it whenever `A` is large enough to see `S³`.
This is the honest limit of what the computation supports.

**Relaxation Map:**

| Variant | Assumption relaxed | Assessment |
|---|---|---|
| O′1 | a fine-tuned `JuJ⁻¹` with cancelling unbounded parts | needs an unbounded-operator argument, not a finite model — the one technically open door left in the whole C11 line |
| O′2 | drop orientability | then the object is not a noncommutative manifold; with C49 (PD fails) what remains is an algebra with an operator |

## Where C11 stands after this

The doubling is unearned from four directions (C44, C45, C48+C50+C51, C49), **plus** an
independent orientability failure (C52) that now survives the `A⊗A°` formulation too. The
root is a single conflict, stated in C52: **anticommutation demands `ι`; orientability
forbids it.** What survives is C46 (if taken, it is a *parity* doubling) and C47 (the
4-dim kernel is isolated — and C48 made that isolation a *selection*).
