PART A  Real harmonics: is  int x*x dS  proportional to r^2 or to r^4?
====================================================================================================
Set-up: x = r sin(th) cos(ph), y = r sin(th) sin(ph), z = r cos(th);  dS = r^2 sin(th) dth dph.
So   x^2 dS = r^4 sin^3(th) cos^2(ph) dth dph   (r^2 from x^2, r^2 from dS).

  [PASS] A1  identity (2): d/dphi[phi/2 + sin(phi)cos(phi)/2] = cos^2(phi)
  int_0^2pi cos^2(phi) dphi = F2(2pi)-F2(0) = pi;   int_0^2pi sin^2(phi) dphi = 2pi - pi = pi
  [PASS] A2  identity (3) as read: d/dtheta[cos(3th)/12 - 3cos(th)/4] = sin^3(th)
  int_0^pi sin^3(theta) dtheta = F3(pi)-F3(0) = 4/3
  [PASS] A3  d/dtheta[-cos^3(th)/3] = cos^2(th) sin(th)
  int_0^pi cos^2(theta) sin(theta) dtheta = 2/3

  int x^2 dS = r^4 * (int sin^3) * (int cos^2) = r^4 * 4/3 * pi = 4*pi*r**4/3
  int y^2 dS = r^4 * (int sin^3) * (int sin^2) = r^4 * 4/3 * pi = 4*pi*r**4/3
  int z^2 dS = r^4 * (int cos^2 sin) * (2 pi)  = r^4 * 2/3 * 2pi        = 4*pi*r**4/3
  mixed: int xy dS ~ int_0^2pi sin(ph)cos(ph) = 0;  xz ~ int cos(ph) = 0;  yz ~ int sin(ph) = 0

  Full double integrals (sympy, independent of the step-by-step route), Gram of (x,y,z) on S^2_r:
  Matrix([[4*pi*r**4/3, 0, 0], [0, 4*pi*r**4/3, 0], [0, 0, 4*pi*r**4/3]])
  [PASS] P1  int x^2 dS = int y^2 dS = int z^2 dS = 4 pi r^4/3 and all mixed integrals vanish (step route)
  [PASS] P1b  full double-integral Gram matrix of (x,y,z) = (4 pi r^4/3) * identity

  Dimension check: x^2 has degree 2 in r, dS has degree 2  => int x^2 dS must have degree 4.
  candidate 4 pi r^2/3 has degree 2;  candidate 4 pi r^4/3 has degree 4
  [PASS] A4  r^4 version passes the dimension test   (restatement, not counted)
  [PASS] A5  NEGATIVE CONTROL: r^2 version FAILS the dimension test for x   (restatement, not counted)
  The r^2 value 4 pi r^2/3 arises from EITHER of two different integrals:
    route 1:  int (x/r)^2 dS = 4*pi*r**2/3   (degree 2): the integral of x/r, not of x;

PART C2  Why the magnitude is sqrt(2): it is forced by the norm
====================================================================================================
With L_+^dagger = L_-, <L_- Y, L_- Y> = <Y, L_+ L_- Y> = l(l+1) - m(m-1) for |l=1,m>.  Direct integral on S^2_r:

  int |L- Y'(1,1)|^2 dS = 2
  int |L- Y'(1,0)|^2 dS = 2
  int |L- Y'(1,-1)|^2 dS = 0
  int |L+ Y'(1,-1)|^2 dS = 2
  int |L+ Y'(1,0)|^2 dS = 2
  int |L+ Y'(1,1)|^2 dS = 0
  [PASS] P4-norm  int |L_pm Y'|^2 dS = l(l+1) - m(m pm 1) = 2,2,0,2,2,0 for every r

====================================================================================================
PART E  'Discover' the complex harmonics from the ladder operators
====================================================================================================
Step 1.  L_z = -i d_phi.  Eigenfunctions of L_z with eigenvalue m: psi = g(r) chi_m(theta) e^{i m phi}.
  dsolve(-i F' = m F) = Eq(F(phi), C1*exp(I*m*phi))   (single-valuedness F(phi+2pi) = F(phi) forces m integer; l = 1 allows m = -1, 0, 1)
  [PASS] E1  L_z eigenfunctions have the phi-dependence e^{i m phi}

Step 2.  Highest weight: L_+ [chi(theta) e^{i phi}] = 0.
  L_+ [chi e^(i phi)] = e^(2 i phi) * (-chi(theta)*cot(theta) + Derivative(chi(theta), theta))  => ODE: -chi(theta)*cot(theta) + Derivative(chi(theta), theta) = 0
  dsolve => Eq(chi(theta), C1*sin(theta))
  [PASS] E2  L_+[chi e^{i phi}] = 0 gives chi = C sin(theta)

Step 3.  Lowest weight: L_- [chi(theta) e^{-i phi}] = 0.
  L_- [chi e^(-i phi)] = e^(-2 i phi) * (chi(theta)*cot(theta) - Derivative(chi(theta), theta))  => ODE: chi(theta)*cot(theta) - Derivative(chi(theta), theta) = 0
  dsolve => Eq(chi(theta), C1*sin(theta))
  [PASS] E3  L_-[chi e^{-i phi}] = 0 gives chi = C' sin(theta)

Negative controls: the wrong annihilation conditions.
  L_- [chi e^(i phi)] = 0   => Eq(chi(theta), C1/sin(theta))
  L_+ [chi e^(-i phi)] = 0  => Eq(chi(theta), C1/sin(theta))
  norm of chi = C/sin(theta): int |chi|^2 sin(theta) dtheta = int dtheta/sin(theta) = -log(1 - cos(epsilon))/2 + log(-cos(epsilon) - 1)/2 - log(cos(epsilon) - 1)/2 + log(cos(epsilon) + 1)/2  ->  oo as epsilon -> 0
  [PASS] E4  NEGATIVE CONTROL: wrong annihilation conditions give chi = C/sin(theta), which is not normalisable   (negative control)

Step 4.  Normalise on S^2_r with the radial factor 1/r (so that Y' = Y(theta,phi)/r, as in Part B).
  int |Y11|^2 dOmega = 8*pi*C*conjugate(C)/3  =>  |C|^2 = 3/(8 pi),  |C| = sqrt(3/(8 pi))   (and likewise |C'|)
  [PASS] E5  normalisation fixes |C| = |C'| = sqrt(3/(8 pi))

Step 5.  Get Y(1,0) two ways and require agreement.
  L_- Y11 = -2*C*cos(theta)      L_+ Y(1,-1) = 2*Cp*cos(theta)
  ||L_- Y11||^2 = 2  => the normalised Y(1,0) is L_- Y11 / sqrt(2): the coefficient sqrt(2) is forced by the norm
