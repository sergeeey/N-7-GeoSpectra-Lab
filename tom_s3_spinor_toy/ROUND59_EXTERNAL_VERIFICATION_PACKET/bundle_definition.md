# Bundle Definition — Round59 External Verification Packet

This file specifies the geometric and representation-theoretic objects
the computation is over. Everything here is standard construction, citable
to the primary source (`AHL2023`, §5.1) — nothing here is a project-
specific result.

## Base geometry

`S⁶`, realized as the homogeneous (nearly-Kähler) space `G₂/SU(3)`, where
`SU(3)` is embedded as the isotropy subgroup fixing a point (equivalently,
fixing a unit imaginary octonion, in the octonionic model of `G₂` as
`\mathrm{Aut}(\mathbb{O})`). This is the standard construction used
throughout `AHL2023` §5.1 and cited consistently across this project.

## Spinor bundle

`Σ = Λ•(ℂ³)`, dimension 8, with the natural `ℤ₂`-grading by exterior
degree parity: `Σ = Σ₊ ⊕ Σ₋`, `dim Σ₊ = dim Σ₋ = 4` (the even-degree and
odd-degree parts of the exterior algebra, respectively).

## Isotropy action

The isotropy representation of `SU(3) = \mathrm{Stab}(pt) \subset G_2` on
`Σ` is generated by `\mathrm{ad}(\nu_i)|_{\mathfrak{m}}` for the 8 `su(3)`
directions `\nu_i` (`AHL2023` Remark 5.2, page 42 of the source), lifted
to the spinor representation via the standard `\mathrm{spin}` lift of the
`so(6)` action these generate. **As a calibration sanity check** (not the
final result): the two Killing spinors `ψ±` defined in `conventions.md`
should be annihilated by every one of these 8 lifted generators — this is
the `SU(3)`-invariance of the Killing spinors, a structural fact
independent of any numeric rank computation, and a useful early gate
before proceeding to the tensor-bundle construction below.

## The twisted tensor bundle

The rank computation this packet asks for lives on `Σ ⊗ Σ` (64-dimensional
complex vector space at each point), split by parity into four blocks:

```
Σ₊⊗Σ₊   Σ₊⊗Σ₋
Σ₋⊗Σ₊   Σ₋⊗Σ₋
```

each block 16-dimensional. The `SU(3)` isotropy action extends to `Σ⊗Σ`
by the Leibniz rule (acting on each tensor factor separately and summing).

- **Domain block:** `Σ₋ ⊗ Σ₊` (odd ⊗ even) — labeled "`Σ_odd⊗Σ_even`" in
  `problem_statement.md`.
- **Target block:** `Σ₊ ⊗ Σ₊` (even ⊗ even) — labeled "`Σ_even⊗Σ_even`"
  in `problem_statement.md`.

Within each of these two 16-dimensional blocks, find the `SU(3)`-invariant
subspace (the joint kernel of all 8 lifted-and-Leibniz-extended isotropy
generators, restricted to that block). **Search the full 16-dimensional
block for each — do not assume a smaller sub-block a priori.** See
`critical_blocks.md` item 1 for the specific historical reason this
caveat exists in this project's own record.

## The map to be ranked

The (Levi-Civita, untwisted) Dirac operator `D`, understood as acting on
the tensor bundle in the standard twisted-Dirac-operator sense (Clifford
multiplication on one factor, covariant derivative built from the Nomizu
data in `conventions.md` on the connection), restricted to map the domain
invariant subspace found above into the target invariant subspace found
above. This restriction is `D⁺|₁` in `problem_statement.md`'s notation.

## What is intentionally NOT specified here

- The dimensions of the two invariant subspaces.
- Any explicit basis for either subspace.
- Any property of the resulting matrix beyond "compute it and find its
  rank."
